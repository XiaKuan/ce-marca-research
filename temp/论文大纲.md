# CE-MARCA 论文大纲

**标题**：基于因果增强多智能体协作的动态微服务根因推理方法

**英文标题**：CE-MARCA: Causal-Enhanced Multi-Agent Collaboration for Dynamic Root Cause Inference in Microservices

---

## 摘要 (Abstract)

**结构**：
1. 背景：微服务系统复杂性增加，根因分析 (RCA) 面临挑战
2. 问题：现有 LLM 方法存在幻觉、效率低、缺乏结构约束
3. 方法：提出 CE-MARCA 框架
   - 双层图结构（静态依赖 + 动态因果）
   - CAHP 协作协议（多智能体 3 轮推理）
   - 动态推理策略（5 种故障模式自适应）
4. 结果：在 MicroRCA 数据集上的实验结果
5. 贡献：准确率提升、效率提升、可解释性增强

**字数**：250-300 字
