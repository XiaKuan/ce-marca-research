# 研究问题定义

版本：v0.1  
创建时间：2026-03-19  
状态：草案

## 研究标题

**基于因果增强多智能体协作的动态微服务根因推理方法**

英文：Causal-Enhanced Multi-Agent Collaboration for Dynamic Root Cause Inference in Microservices

## 核心研究问题

**主问题**：如何利用因果发现和多智能体协作技术，提高微服务系统根因分析的准确性、效率和可解释性？

**子问题**：

1. **因果图构建**：如何从微服务监控数据（指标、日志、追踪）中高效构建因果图？
   - 静态依赖图 vs 动态因果图的关系是什么？
   - 如何选择因果发现算法（Granger、NOTEARS、PC）以适应不同场景？

2. **多智能体协作**：如何设计多智能体架构以充分利用专业分工的优势？
   - 智能体之间如何通信和协调？
   - 如何解决智能体之间的冲突或分歧？
   - 如何避免多智能体带来的额外开销？

3. **动态推理策略**：如何根据故障模式动态调整推理策略？
   - 如何识别故障模式（性能下降、错误率上升、延迟增加等）？
   - 不同故障模式对应何种最优推理策略？
   - 如何实现策略的在线切换？

4. **LLM 幻觉抑制**：如何利用因果约束减少 LLM 在根因分析中的幻觉？
   - 因果图如何约束 LLM 的推理空间？
   - 如何验证 LLM 生成的因果解释的可靠性？

## 研究假设

**H1**：相比单智能体方法，多智能体协作方法在 Top-1 Accuracy 上提升 ≥ 15%

**H2**：相比无因果约束的方法，因果增强方法在 Precision@K 上提升 ≥ 20%

**H3**：相比静态推理流程，动态推理策略减少推理步骤 ≥ 30%

**H4**：因果约束显著减少 LLM 幻觉（幻觉率降低 ≥ 40%）

## 研究范围

**包含**：
- 微服务系统的离线根因分析（post-mortem）
- 公开数据集（MicroRCA、AIOps Challenge 等）
- 开源 LLM（Llama-3-8B、Qwen 等）推理
- 单 GPU 或 CPU 环境

**不包含**：
- 实时在线干预（安全考虑）
- 专有生产数据
- 大模型训练（仅推理和轻量微调）
- 非微服务架构（如单体应用、Serverless）

## 预期贡献

1. **方法贡献**：提出因果增强多智能体协作框架（Causal-MAC）
2. **技术贡献**：
   - 双层图结构（静态依赖图 + 动态因果图）
   - 故障模式感知的动态推理策略
   - 因果约束的 LLM 推理机制
3. **实证贡献**：
   - 在 MicroRCA 等基准上的系统评估
   - 开源代码和配置
4. **理论贡献**：
   - 因果图与多智能体协作的形式化关系
   - 幻觉抑制的理论分析

## 评估指标

| 指标 | 定义 | 目标值 |
|------|------|--------|
| Top-1 Accuracy | 根因定位准确率 | ≥ 80% |
| Precision@K | 前 K 个候选中包含根因的比例 | ≥ 85% (K=3) |
| 推理步骤 | 智能体查询次数 | 减少 ≥ 30% |
| Token 成本 | 消耗的 token 数量 | 降低 ≥ 30% |
| 推理时间 | 单次 RCA 耗时 | < 5 分钟 |
| 幻觉率 | 错误因果链比例 | 降低 ≥ 40% |

## 基线方法

1. **Standard RAG**：标准检索增强生成，无图约束
2. **Graph-Constrained Agent**：前期研究的图约束单智能体方法
3. **Traditional ML**：Random Forest、XGBoost 等传统机器学习方法
4. **mABC**：多智能体区块链启发式方法（最新相关工作）

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 因果发现计算开销大 | 高 | 使用轻量级算法，预计算因果图 |
| 多智能体协调复杂 | 中 | 简化协议，集中式协调 |
| 数据集访问受限 | 高 | 准备多个备选数据集 |
| GPU 资源不足 | 中 | 使用量化模型，优化推理 |
